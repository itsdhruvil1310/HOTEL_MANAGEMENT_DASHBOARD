# 🏨 Hotel Management Dashboard

## 📌 Overview

The **Hotel Management Dashboard** is an interactive data analytics project created using an **Excel dataset** to analyze hotel bookings, revenue, room availability, customer demographics, and booking performance.

The project transforms raw hotel management data into meaningful **KPIs, visualizations, and business insights**, helping hotel management understand booking trends, customer behavior, revenue performance, and room utilization.

---

## 🎯 Project Objectives

- Analyze hotel booking performance
- Track total revenue generated
- Monitor room availability and bookings
- Analyze booking status
- Compare different room types
- Understand customer demographics
- Analyze payment methods
- Compare new and existing customers
- Identify booking and revenue trends
- Support data-driven hotel management decisions

---

## 📊 Dashboard Analysis

The dashboard provides insights into:

### 🏨 Hotel Performance
- Hotel-wise booking analysis
- Hotel-wise revenue performance
- Room availability
- Room booking volume
- Capacity utilization

### 🛏️ Room Analysis
- Room type distribution
- Room type booking performance
- Room availability vs. booked rooms
- Revenue generated by room type

### 💰 Revenue Analysis
- Total revenue
- Revenue by hotel
- Revenue by room type
- Price and discount analysis

### 📅 Booking Analysis
- Booking trends over time
- Booking status analysis
- Cancelled, pending, and confirmed bookings
- Customer booking patterns

### 👥 Customer Analysis
- New vs. existing customers
- Customer age distribution
- Customer gender analysis
- Customer demographics by location

### 💳 Payment Analysis
- Online payments
- Credit card payments
- Other payment methods
- Payment method distribution

## 📂 Dataset

The dataset contains **10,000 hotel booking records** with 19 attributes, including:

- Hotel Name
- Room Type
- City
- Country
- Payment Mode
- Price
- Room Available
- Room Booked
- Booking Date
- Customer ID
- Customer Type
- Room Type Count
- Total Revenue
- Discount
- Booking Status
- Customer Name
- Customer Age
- Customer Gender
- Total Capacity
